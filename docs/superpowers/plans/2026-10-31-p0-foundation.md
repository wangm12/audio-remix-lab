# Phase 0 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make audio-remix-lab safe and testable as a multi-user app. Sources are stored under server-side storage keys, every lookup is owner-scoped, media is cookie-authenticated, Suno is gone, FastAPI can serve the built UI, and ACE-Step v0.1.8 starts with one `make` command. Backend and frontend test suites guard all of it.

**Architecture:** Keep the existing FastAPI + SQLAlchemy async + Alembic backend and the React 19 + Vite 8 + TanStack UI, and change them in small vertical slices.
- Every slice lands with its tests. Backend tests run against a real PostgreSQL database migrated by Alembic and mock ACE-Step HTTP with respx. UI tests run in Vitest with Testing Library and msw.
- Each task leaves both apps building and passing.

**Tech Stack:**
- Backend: Python 3.12, FastAPI 0.162, Starlette 1.10, SQLAlchemy 2.1 (asyncpg), Alembic, bcrypt 5, python-jose, sse-starlette, pytest 9 + pytest-asyncio 1.4 + respx 0.23, ruff 0.17, uv (lock only).
- UI: Node 24 / npm 11, React 19, Vite 8, TypeScript 6, TanStack Router/Query, Vitest 5, jsdom 30, Testing Library, msw 2.
- Infrastructure: Docker Compose (PostgreSQL 16), FFmpeg 8, ACE-Step 1.5 v0.1.8 (`uv run acestep-api`).

**Spec:** `docs/superpowers/specs/2026-10-31-remix-studio-v2-design.md`. Where this plan and the spec disagree, the spec wins; report the conflict instead of guessing.

## Global Constraints

- **Python and Node versions:**
  - Python 3.12 (`python3.12`), with the backend venv at `song-remix-backend/.venv`. Backend dependencies are installed from `song-remix-backend/requirements.lock`, which is generated by `uv pip compile requirements.txt requirements-dev.txt --python-version 3.12 --output-file requirements.lock`.
  - Node 24 with npm 11 (`.nvmrc` = `24`). npm 10 cannot install the test dependencies. Run `source ~/.nvm/nvm.sh && nvm use 24` in every shell before any `npm` command; `node -v` must print `v24.*`.
- **Services:**
  - PostgreSQL 16 from `docker compose` (project `audio-remix-lab`, postgres only, published on `127.0.0.1:5432`).
  - FFmpeg (`ffmpeg`, `ffprobe`) on PATH.
- **Test isolation:**
  - The test database `remix_studio_test` is dropped, recreated and migrated with `alembic upgrade head` once per pytest session. Never use `Base.metadata.create_all`. Migration tests use `remix_studio_migrations_test`. `TEST_DATABASE_URL` overrides the server.
  - Tests never contact ACE-Step: `ACESTEP_API_BASE=http://acestep.test`, and HTTP is mocked with respx. Tests that need the real engine are marked `real_engine` and deselected by default.
  - No audio files are committed. Tests synthesize WAV with `tests.helpers.write_sine_wav`.
- **Secrets:** the backend refuses to start when `JWT_SECRET` is empty, `dev-secret-change-in-production`, `change-me-in-production`, or shorter than 32 characters. `make env` writes `secrets.token_urlsafe(48)`.
- **Media cookie and token scopes:**
  - The cookie is `remix_media` with `HttpOnly`, `SameSite=Lax`, `Path=/api`, `Max-Age=JWT_EXPIRE_MINUTES*60` (86400), and `Secure` if and only if `COOKIE_SECURE=true`.
  - JWT `scope` claim is `access` or `media`; a token without `scope` is an access token.
  - The cookie is accepted only by `GET /api/tasks/{id}/audio` and `GET /api/tasks/{id}/stream`. A media token sent as Bearer gets 401.
- **Passwords:** 8 characters minimum and 72 UTF-8 bytes maximum; `verify_password` returns `False` above 72 bytes. Usernames are 1–100 characters.
- **Registration:** open unless `REGISTRATION_INVITE_CODE` is set. The code is compared with `secrets.compare_digest`; a mismatch returns 403 `"A valid invite code is required to register"`.
- **Login rate limit:** 10 failed attempts per 300 s per client IP (`LOGIN_RATE_LIMIT_ATTEMPTS=10`, `LOGIN_RATE_LIMIT_WINDOW_SECONDS=300`), then 429 with `Retry-After`. A successful login resets the counter. The limiter is in-memory and single-process.
- **Ownership:** every song, task, preset and stream lookup filters by owner. A foreign id returns 404 with the same body as a missing id. Built-in presets are readable by every user and writable by none.
- **No paths in responses:** no API response or SSE payload contains a filesystem path, storage key, ACE-Step URL or `engine_task_id`. `source_audio_path` becomes `has_source` and `output_audio_path` becomes `has_output`.
- **Storage keys:** sources live at `users/{user_id}/songs/{song_id}/source.{mp3|wav|flac|ogg|m4a}` and are resolved only through `app.utils.storage.resolve_key`. Writes are atomic (`.part` file, then `os.replace`).
- **Uploads:**
  - The endpoint is `POST /api/songs/{id}/source`, multipart field `file`, streamed in 1 MiB chunks.
  - 413 above `MAX_UPLOAD_MB=128` (MiB). 400 when the file is empty, is not audio according to ffprobe, or is longer than `MAX_SOURCE_DURATION_SECONDS=600`.
  - The stored extension comes from ffprobe.
  - `/api/upload/audio` and `SongUpdate.source_audio_path` are removed.
- **Serving:** `HOST` defaults to `127.0.0.1`. `make serve` builds the UI and runs one uvicorn process without `--reload`, with FastAPI serving `song-remix-ui/dist` and an SPA fallback.
- **ACE-Step:**
  - Submodule `acestep` is pinned to v0.1.8 (`dce621408bee8c31b4fcf4811682eb9359e1bc94`).
  - Start it only via `make acestep` (`uv run acestep-api --host 127.0.0.1 --port 8001`), never via `start_api_server_macos.sh`.
  - Defaults: `ACESTEP_MODEL=acestep-v15-turbo`, `ACESTEP_LM_MODEL=acestep-5Hz-lm-1.7B`.
- **Suno:** nothing named Suno or 2Captcha remains in code, config, compose, env files or docs.
- **UI scope:** P0 UI changes are functional only; the redesign is P2. Desktop only.
- **Gate after every task.** Both commands must pass. Task 1 runs only the backend line; Task 2 runs the backend line plus `npm run lint && npm run build`.
  - `cd song-remix-backend && .venv/bin/ruff check . && .venv/bin/pytest -q`
  - `cd song-remix-ui && npm test && npm run lint && npm run build`
- **Commits:** one commit per task with the message given in the task, and `git add` with the explicit paths listed. Never `git add -A` or `git add .`.
- **Makefile:** recipe lines start with a TAB character, never spaces.

## How edits are written

- "Create `path`:" — create a new file with exactly the block's content.
- "Replace the contents of `path` with:" — overwrite the whole file.
- "In `path`, replace:" followed by a block, then "with:" and a second block. The first block occurs exactly once in the file; replace it with the second, character for character.
- "Append to `path`:" — add the block at the end of the file.
- "Delete `path`." — `git rm` it in the commit step.

Blocks are exact. Don't reformat, reorder imports or "improve" neighbouring code. If a "replace" block does not match, stop and report it; don't improvise.

T = TypeVar("T")


def _run_in_thread(factory: Callable[[], Coroutine[Any, Any, T]]) -> T:
    """Run a coroutine on a private event loop in a worker thread, never on the test loop."""
    with ThreadPoolExecutor(max_workers=1) as pool:
        return pool.submit(lambda: asyncio.run(factory())).result()


def asyncpg_dsn(url: str, database: str | None = None) -> str:
    parsed = make_url(url).set(drivername="postgresql")
    if database is not None:
        parsed = parsed.set(database=database)
    return parsed.render_as_string(hide_password=False)


def database_url(url: str, database: str) -> str:
    return make_url(url).set(database=database).render_as_string(hide_password=False)


def recreate_database(url: str) -> None:
    name = make_url(url).database

    async def _recreate() -> None:
        conn = await asyncpg.connect(asyncpg_dsn(url, database="postgres"))
        try:
            await conn.execute(f'DROP DATABASE IF EXISTS "{name}" WITH (FORCE)')
            await conn.execute(f'CREATE DATABASE "{name}"')
        finally:
            await conn.close()

    _run_in_thread(_recreate)


def fetch_sql(url: str, sql: str, *args: Any) -> list[tuple]:
    async def _fetch() -> list[tuple]:
        conn = await asyncpg.connect(asyncpg_dsn(url))
        try:
            return [tuple(row) for row in await conn.fetch(sql, *args)]
        finally:
            await conn.close()

    return _run_in_thread(_fetch)


def execute_sql(url: str, sql: str, *args: Any) -> None:
    async def _execute() -> None:
        conn = await asyncpg.connect(asyncpg_dsn(url))
        try:
            await conn.execute(sql, *args)
        finally:
            await conn.close()

    _run_in_thread(_execute)


def truncate_all_tables(url: str) -> None:
    async def _truncate() -> None:
        conn = await asyncpg.connect(asyncpg_dsn(url))
        try:
            rows = await conn.fetch(
                "SELECT tablename FROM pg_tables WHERE schemaname = 'public' AND tablename <> 'alembic_version'"
            )
            if rows:
                tables = ", ".join(f'"{row["tablename"]}"' for row in rows)
                await conn.execute("SET lock_timeout = '5s'")
                await conn.execute(f"TRUNCATE {tables} RESTART IDENTITY CASCADE")
        finally:
            await conn.close()

    _run_in_thread(_truncate)


def run_alembic(url: str, *args: str) -> str:
    env = {**os.environ, "DATABASE_URL": url}
    result = subprocess.run(
        [sys.executable, "-m", "alembic", *args], cwd=BACKEND_DIR, env=env, capture_output=True, text=True
    )
    if result.returncode != 0:
        raise AssertionError(f"alembic {' '.join(args)} failed:\n{result.stdout}\n{result.stderr}")
    return result.stdout + result.stderr

def write_sine_wav(path: Path, seconds: float = 1.0, sample_rate: int = 8000, frequency: float = 440.0) -> Path:
    import math
    import struct
    import wave

    frames = int(seconds * sample_rate)
    samples = (int(12000 * math.sin(2 * math.pi * frequency * i / sample_rate)) for i in range(frames))
    with wave.open(str(path), "wb") as wav:
        wav.setnchannels(1)
        wav.setsampwidth(2)
        wav.setframerate(sample_rate)
        wav.writeframes(b"".join(struct.pack("<h", sample) for sample in samples))
    return path


def convert_audio(source: Path, destination: Path) -> Path:
    subprocess.run(["ffmpeg", "-y", "-v", "error", "-i", str(source), str(destination)], check=True)
    return destination

```python
import os
import shutil
import uuid
from pathlib import Path, PurePosixPath

from app.config import settings

ALLOWED_SOURCE_EXTENSIONS = frozenset({"mp3", "wav", "flac", "ogg", "m4a"})


class InvalidStorageKey(ValueError):
    """A storage key that is not a safe relative path inside STORAGE_PATH."""


def storage_root() -> Path:
    root = Path(settings.STORAGE_PATH).expanduser().resolve()
    root.mkdir(parents=True, exist_ok=True)
    return root


def resolve_key(key: str) -> Path:
    if not key or "\x00" in key or "\\" in key:
        raise InvalidStorageKey(f"Invalid storage key: {key!r}")
    if PurePosixPath(key).is_absolute() or any(part in ("", ".", "..") for part in key.split("/")):
        raise InvalidStorageKey(f"Invalid storage key: {key!r}")
    root = storage_root()
    resolved = (root / key).resolve()
    if resolved == root or not resolved.is_relative_to(root):
        raise InvalidStorageKey(f"Storage key escapes the storage root: {key!r}")
    return resolved


def song_prefix(user_id: uuid.UUID | str, song_id: uuid.UUID | str) -> str:
    return f"users/{user_id}/songs/{song_id}"


def song_source_key(user_id: uuid.UUID | str, song_id: uuid.UUID | str, extension: str) -> str:
    if extension not in ALLOWED_SOURCE_EXTENSIONS:
        raise InvalidStorageKey(f"Unsupported source extension: {extension!r}")
    return f"{song_prefix(user_id, song_id)}/source.{extension}"


def _partial_path(path: Path) -> Path:
    return path.with_name(f"{path.name}.{uuid.uuid4().hex}.part")


def write_key(key: str, data: bytes) -> Path:
    path = resolve_key(key)
    path.parent.mkdir(parents=True, exist_ok=True)
    partial = _partial_path(path)
    partial.write_bytes(data)
    os.replace(partial, path)
    return path


def store_file(key: str, source: Path) -> Path:
    path = resolve_key(key)
    path.parent.mkdir(parents=True, exist_ok=True)
    partial = _partial_path(path)
    shutil.copyfile(source, partial)
    os.replace(partial, path)
    return path


def delete_key(key: str | None) -> None:
    if not key:
        return
    try:
        path = resolve_key(key)
    except InvalidStorageKey:
        return
    path.unlink(missing_ok=True)


def delete_prefix(prefix: str) -> None:
    path = resolve_key(prefix)
    if path.is_dir():
        shutil.rmtree(path)


def legacy_file_path(path: str | None) -> Path | None:
    """Resolve a legacy path column (e.g. generation_tasks.output_audio_path); trusted only inside STORAGE_PATH."""
    if not path:
        return None
    candidate = Path(path).expanduser().resolve()
    if candidate.is_relative_to(storage_root()) and candidate.is_file():
        return candidate
    return None


def delete_legacy_file(path: str | None) -> None:
    candidate = legacy_file_path(path)
    if candidate is not None:
        candidate.unlink(missing_ok=True)


def get_upload_dir() -> str:
    path = os.path.join(settings.STORAGE_PATH, "uploads")
    os.makedirs(path, exist_ok=True)
    return path


def save_upload(content: bytes, original_filename: str) -> str:
    ext = os.path.splitext(original_filename)[1] or ".mp3"
    filename = f"{uuid.uuid4()}{ext}"
    filepath = os.path.abspath(os.path.join(get_upload_dir(), filename))
    with open(filepath, "wb") as f:
        f.write(content)
    return filepath
```

```python
import asyncio
import json
import shutil
from dataclasses import dataclass
from pathlib import Path

PROBE_TIMEOUT_SECONDS = 30.0

FORMAT_EXTENSIONS = {
    "mp3": "mp3",
    "wav": "wav",
    "flac": "flac",
    "ogg": "ogg",
    "mov,mp4,m4a,3gp,3g2,mj2": "m4a",
}


class AudioProbeError(ValueError):
    """The file is not audio the app accepts."""


@dataclass(frozen=True)
class AudioProbe:
    duration: float
    format_name: str
    codec_name: str
    extension: str


async def probe_audio(path: Path) -> AudioProbe:
    ffprobe = shutil.which("ffprobe")
    if ffprobe is None:
        raise RuntimeError("ffprobe is not installed; install FFmpeg (brew install ffmpeg)")
    process = await asyncio.create_subprocess_exec(
        ffprobe,
        "-v",
        "error",
        "-print_format",
        "json",
        "-show_format",
        "-show_streams",
        str(path),
        stdout=asyncio.subprocess.PIPE,
        stderr=asyncio.subprocess.PIPE,
    )
    try:
        stdout, _ = await asyncio.wait_for(process.communicate(), timeout=PROBE_TIMEOUT_SECONDS)
    except TimeoutError:
        process.kill()
        await process.wait()
        raise AudioProbeError("Timed out while inspecting the audio file") from None
    if process.returncode != 0:
        raise AudioProbeError("The file is not a readable audio file")
    try:
        info = json.loads(stdout or b"{}")
    except json.JSONDecodeError:
        raise AudioProbeError("The file is not a readable audio file") from None

    streams = [stream for stream in info.get("streams", []) if stream.get("codec_type") == "audio"]
    if not streams:
        raise AudioProbeError("The file has no audio stream")
    container = info.get("format", {})
    format_name = container.get("format_name", "")
    extension = FORMAT_EXTENSIONS.get(format_name)
    if extension is None:
        raise AudioProbeError(f"Unsupported audio container: {format_name or 'unknown'}")
    try:
        duration = float(container.get("duration") or streams[0].get("duration") or 0)
    except (TypeError, ValueError):
        duration = 0.0
    if duration <= 0:
        raise AudioProbeError("Could not determine the audio duration")
    return AudioProbe(
        duration=duration,
        format_name=format_name,
        codec_name=streams[0].get("codec_name", ""),
        extension=extension,
    )
```

from datetime import UTC, datetime, timedelta

import bcrypt
from jose import JWTError, jwt

from app.config import settings

ACCESS_SCOPE = "access"
MEDIA_SCOPE = "media"


def hash_password(password: str) -> str:
    return bcrypt.hashpw(password.encode("utf-8"), bcrypt.gensalt()).decode("utf-8")


def verify_password(plain: str, hashed: str) -> bool:
    return bcrypt.checkpw(plain.encode("utf-8"), hashed.encode("utf-8"))


def create_access_token(subject: str, expires_delta: timedelta | None = None, scope: str = ACCESS_SCOPE) -> str:
    expire = datetime.now(UTC) + (expires_delta or timedelta(minutes=settings.JWT_EXPIRE_MINUTES))
    payload = {"sub": subject, "exp": expire, "scope": scope}
    return jwt.encode(payload, settings.JWT_SECRET, algorithm=settings.JWT_ALGORITHM)


def decode_access_token(token: str, scope: str = ACCESS_SCOPE) -> str | None:
    try:
        payload = jwt.decode(token, settings.JWT_SECRET, algorithms=[settings.JWT_ALGORITHM])
    except JWTError:
        return None
    if payload.get("scope", ACCESS_SCOPE) != scope:
        return None
    subject = payload.get("sub")
    return subject if isinstance(subject, str) else None

The old generator held the request's session open for the whole stream and sent file paths. The new one opens a session for each poll, so it sees commits from the generation worker, and it sends only `has_output`.

```python
import asyncio
import json
from collections.abc import AsyncIterator
from uuid import UUID

from app.database import async_session
from app.models.task import GenerationTask

POLL_INTERVAL_SECONDS = 2.0
TERMINAL_STATUSES = frozenset({"completed", "failed"})


def task_progress_payload(task: GenerationTask) -> dict:
    return {
        "status": task.status,
        "started_at": task.started_at.isoformat() if task.started_at else None,
        "completed_at": task.completed_at.isoformat() if task.completed_at else None,
        "error_message": task.error_message,
        "has_output": task.has_output,
    }


async def task_event_generator(task_id: UUID, poll_interval: float = POLL_INTERVAL_SECONDS) -> AsyncIterator[dict]:
    while True:
        async with async_session() as db:
            task = await db.get(GenerationTask, task_id)
            payload = task_progress_payload(task) if task is not None else None
        if payload is None:
            yield {"event": "error", "data": json.dumps({"error": "Task not found"})}
            return
        yield {"event": "progress", "data": json.dumps(payload)}
        if payload["status"] in TERMINAL_STATUSES:
            return
        await asyncio.sleep(poll_interval)
```

Create `song-remix-backend/app/core/rate_limit.py`:

```python
import math
import time
from collections import deque
from collections.abc import Callable

from app.config import settings


class SlidingWindowLimiter:
    """In-memory sliding-window counter keyed by client IP. Valid only for a single backend process."""

    def __init__(self, max_events: int, window_seconds: float, clock: Callable[[], float] = time.monotonic) -> None:
        self.max_events = max_events
        self.window_seconds = window_seconds
        self._clock = clock
        self._events: dict[str, deque[float]] = {}

    def _recent(self, key: str, now: float) -> deque[float]:
        events = self._events.get(key)
        if events is None:
            return deque()
        while events and events[0] <= now - self.window_seconds:
            events.popleft()
        if not events:
            del self._events[key]
        return events

    def retry_after(self, key: str) -> int:
        """Seconds until `key` may try again; 0 when it is not blocked."""
        now = self._clock()
        events = self._recent(key, now)
        if len(events) < self.max_events:
            return 0
        return max(1, math.ceil(events[0] + self.window_seconds - now))

    def hit(self, key: str) -> None:
        now = self._clock()
        self._recent(key, now)
        self._events.setdefault(key, deque()).append(now)

    def reset(self, key: str | None = None) -> None:
        if key is None:
            self._events.clear()
        else:
            self._events.pop(key, None)


login_rate_limiter = SlidingWindowLimiter(
    max_events=settings.LOGIN_RATE_LIMIT_ATTEMPTS,
    window_seconds=settings.LOGIN_RATE_LIMIT_WINDOW_SECONDS,
)
```

router = APIRouter(prefix="/api/auth", tags=["auth"])

MEDIA_COOKIE_PATH = "/api"


def set_media_cookie(response: Response, user: User) -> None:
    response.set_cookie(
        key=MEDIA_COOKIE_NAME,
        value=create_access_token(subject=str(user.id), scope=MEDIA_SCOPE),
        max_age=settings.JWT_EXPIRE_MINUTES * 60,
        path=MEDIA_COOKIE_PATH,
        httponly=True,
        secure=settings.COOKIE_SECURE,
        samesite="lax",
    )


def _client_key(request: Request) -> str:
    return request.client.host if request.client else "unknown"


@router.post("/register", response_model=TokenResponse, status_code=status.HTTP_201_CREATED)
async def register(req: RegisterRequest, response: Response, db: AsyncSession = Depends(get_db)):
    invite = settings.REGISTRATION_INVITE_CODE
    if invite and not secrets.compare_digest((req.invite_code or "").encode("utf-8"), invite.encode("utf-8")):
        raise HTTPException(status_code=status.HTTP_403_FORBIDDEN, detail="A valid invite code is required to register")
    try:
        user = await register_user(db, req.email, req.username, req.password)
    except ValueError as e:
        raise HTTPException(status_code=status.HTTP_409_CONFLICT, detail=str(e)) from e
    set_media_cookie(response, user)
    return TokenResponse(access_token=create_token_for_user(user))


@router.post("/login", response_model=TokenResponse)
async def login(req: LoginRequest, request: Request, response: Response, db: AsyncSession = Depends(get_db)):
    key = _client_key(request)
    retry_after = login_rate_limiter.retry_after(key)
    if retry_after:
        raise HTTPException(
            status_code=status.HTTP_429_TOO_MANY_REQUESTS,
            detail="Too many failed login attempts; try again later",
            headers={"Retry-After": str(retry_after)},
        )
    user = await authenticate_user(db, req.email, req.password)
    if user is None:
        login_rate_limiter.hit(key)
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Invalid credentials")
    login_rate_limiter.reset(key)
    set_media_cookie(response, user)
    return TokenResponse(access_token=create_token_for_user(user))


@router.post("/logout", status_code=status.HTTP_204_NO_CONTENT)
async def logout(response: Response) -> None:
    response.delete_cookie(
        key=MEDIA_COOKIE_NAME,
        path=MEDIA_COOKIE_PATH,
        httponly=True,
        secure=settings.COOKIE_SECURE,
        samesite="lax",
    )


@router.get("/me", response_model=UserResponse)
async def me(response: Response, current_user: User = Depends(get_current_user)):
    set_media_cookie(response, current_user)
    return current_user

from fastapi import FastAPI, HTTPException, status
from fastapi.responses import FileResponse

IMMUTABLE_CACHE = "public, max-age=31536000, immutable"
NO_CACHE = "no-cache"


def mount_frontend(app: FastAPI, dist_dir: Path) -> None:
    """Serve the built SPA from FastAPI. Call after every API router is included."""
    root = dist_dir.resolve()
    index = root / "index.html"
    if not index.is_file():
        raise RuntimeError(f"Frontend build not found at {index}; run `npm run build` in song-remix-ui first")

    @app.get("/{full_path:path}", include_in_schema=False)
    async def spa(full_path: str) -> FileResponse:
        if full_path == "api" or full_path.startswith("api/"):
            raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Not Found")
        candidate = (root / full_path).resolve()
        if full_path and candidate.is_relative_to(root) and candidate.is_file():
            cache = IMMUTABLE_CACHE if full_path.startswith("assets/") else NO_CACHE
            return FileResponse(candidate, headers={"Cache-Control": cache})
        return FileResponse(index, headers={"Cache-Control": NO_CACHE})

## Sharing with other people

By default, `make dev` and `make serve` listen on 127.0.0.1, so only your Mac can reach them.

`make serve` builds the UI, then serves the UI and the API together from FastAPI on port 8000, without auto-reload:

```bash
make serve                  # http://127.0.0.1:8000
make serve HOST=0.0.0.0     # reachable from your LAN at http://<your-mac-ip>:8000
```

You can also put `HOST=0.0.0.0` in `.env`.

- **LAN.** Use `HOST=0.0.0.0`. The traffic is plain HTTP, so do this only on a network you trust.
- **Internet.** Keep `HOST=127.0.0.1` and publish port 8000 through an HTTPS tunnel, such as `cloudflared tunnel --url http://127.0.0.1:8000` or `tailscale serve 8000`. Set `COOKIE_SECURE=true` in `.env` whenever the app is reached over HTTPS.
- **Invite only.** Set `REGISTRATION_INVITE_CODE` so that new accounts need the code to sign up.

## Security notes

- **Tokens and the media cookie.** API calls authenticate with a bearer token. Logging in also sets the `remix_media` cookie (HttpOnly, SameSite=Lax, path `/api`). It is accepted only by the audio and progress-stream routes, and its token is rejected when used as a bearer token.
- **Ownership.** Songs, generations and presets are checked against their owner; other users get 404.
- **File paths.** Responses never contain file paths. Files live under `STORAGE_PATH/users/<user>/songs/<song>/`.
- **Passwords and login limits.**
  - Passwords must be between 8 characters and 72 bytes long.
  - Failed logins are limited per client IP (`LOGIN_RATE_LIMIT_ATTEMPTS` per `LOGIN_RATE_LIMIT_WINDOW_SECONDS`).
  - During `make dev` every browser reaches the backend through the Vite proxy as 127.0.0.1, so they all share one limit.
